مرجع شامل للمتغيرات وأنواع البيانات في OpenTofu

📋 أساسيات المتغيرات (Variable Basics)

المتغيرات تسمح لك بجعل الكود قابلاً لإعادة الاستخدام ومرناً. يتم تعريفها في ملف variables.tf واستخدامها في main.tf.

📄 تعريف متغير (في variables.tf)

variable "instance_type" {
  description = "حجم الماكينة الافتراضية"
  type        = string
  default     = "t2.micro"
}

📄 استخدام المتغير (في main.tf)

resource "aws_instance" "web" {
  ami           = var.ami
  instance_type = var.instance_type
}

💡 مكونات المتغير

  • description: وصف اختياري يوضح الغرض من المتغير
  • type: نوع البيانات (string, number, bool, list, map, object, tuple)
  • default: القيمة الافتراضية إذا لم يتم تمرير قيمة

النوع التصنيف الوصف مثال
string Primitive نص واحد "t2.micro"

tuple Structural قائمة بأنواع مختلفة ["str", 5, true]

🔤 الأنواع الأساسية (Primitive Types)

1️⃣ String (نص)

variable "instance_type" {
  description = "حجم الماكينة"
  type        = string
  default     = "t2.micro"
}

variable "ami" {
  description = "معرف صورة النظام"
  type        = string
  default     = "ami-01211123231yt211kj1k3"
}

2️⃣ Number (رقم)

variable "count" {
  description = "عدد الماكينات"
  type        = number
  default     = 2
}

variable "cpu_cores" {
  type    = number
  default = 4
}

3️⃣ Boolean (منطقي)

variable "monitoring" {
  description = "تفعيل المراقبة التفصيلية"
  type        = bool
  default     = true
}

variable "enable_backup" {
  type    = bool
  default = false
}

📚 أنواع المجموعات (Collection Types)

1️⃣ List (قائمة)

قائمة مرتبة من عناصر نفس النوع. يتم الوصول للعناصر عبر الفهرس (index) الذي يبدأ من 0. 

# قائمة نصوص
variable "servers" {
  type    = list(string)
  default = ["web1", "web2", "web3"]
}

# قائمة أرقام
variable "prefix" {
  type    = list(number)
  default = [1, 2, 3]
}

# الاستخدام في المورد
resource "aws_instance" "web" {
  ami           = var.ami
  instance_type = var.instance_type
  tags = {
    Name = var.servers[0]  # web1
  }
}

2️⃣ Map (خريطة)

مجموعة من أزواج مفتاح-قيمة. يتم الوصول للقيم عبر المفتاح. 

# خريطة نصوص
variable "instance_type" {
  type = map(string)
  default = {
    "production"  = "m5.large"
    "development" = "t2.micro"
  }
}

# خريطة أرقام
variable "servers_count" {
  type = map(number)
  default = {
    "web"   = 3
    "db"    = 1
    "agent" = 2
  }
}

# الاستخدام في المورد
resource "aws_instance" "production" {
  ami           = var.ami
  instance_type = var.instance_type["production"]  # m5.large
}

💡 الفرق بين List و Map

  • List: الوصول عبر الفهرس var.servers[0]
  • Map: الوصول عبر المفتاح var.instance_type["production"]

🏗️ الأنواع الهيكلية (Structural Types)

1️⃣ Object (كائن)

كائن بخصائص محددة، كل خاصية لها نوع معين. مفيد لتمثيل بيانات معقدة. 

variable "bella" {
  type = object({
    name         = string
    color        = string
    age          = number
    food         = list(string)
    favorite_pet = bool
  })
  default = {
    name         = "bella"
    color        = "brown"
    age          = 7
    food         = ["fish", "chicken", "turkey"]
    favorite_pet = true
  }
}

# الاستخدام
output "pet_name" {
  value = var.bella.name  # bella
}

output "pet_food" {
  value = var.bella.food[0]  # fish
}

2️⃣ Tuple (مجموعة مرتبة)

قائمة مرتبة يمكن أن تحتوي على أنواع مختلفة. كل عنصر له نوع محدد. 

variable "web" {
  type    = tuple([string, number, bool])
  default = ["web1", 7, true]
}

# الاستخدام
output "server_name" {
  value = var.web[0]  # web1
}

output "server_port" {
  value = var.web[1]  # 7
}

🎤 سؤال مقابلة شائع

ما الفرق بين List و Tuple؟
• List: جميع العناصر يجب أن تكون نفس النوع، والطول غير محدد مسبقاً.
• Tuple: كل عنصر يمكن أن يكون نوع مختلف، والطول والأنواع محددة مسبقاً.

🚀 طرق تمرير المتغيرات

1️⃣ القيمة الافتراضية (في الملف)

# variables.tf
variable "instance_type" {
  default = "t2.micro"
}

2️⃣ عبر سطر الأوامر (-var)

# تمرير متغير واحد
tofu apply -var "ami=ami-878idod" -var "instance_type=t2.micro"

# تمرير متغير من نوع معقد
tofu apply -var 'instance_type={"production"="m5.large"}'

3️⃣ عبر متغيرات البيئة (Environment Variables)

# Linux/Mac
export TF_VAR_instance_type="t3.micro"
export TF_VAR_ami="ami-878idod"
tofu apply

# Windows (PowerShell)
$env:TF_VAR_instance_type = "t3.micro"
tofu apply

4️⃣ عبر ملف متغيرات (.tfvars)

# terraform.tfvars (يتم قراءته تلقائياً)
instance_type = "t2.micro"
ami           = "ami-878idod"

# أو ملف مخصص
tofu apply -var-file="prod.tfvars"
الطريقة متى تستخدمها
default في الملف قيم ثابتة لا تتغير بين البيئات
-var تجاوز سريع أثناء الاختبار
TF_VAR_* أسرار أو قيم حساسة (لا تظهر في التاريخ)
.tfvars بيئات مختلفة (dev, staging, prod)

🎯 مثال كامل من الملف الأصلي

📄 variables.tf

variable "ami" {
  description = "Type of AMI to use"
  type        = string
  default     = "ami-01211123231yt211kj1k3"
}

variable "instance_type" {
  description = "size of EC2"
  type        = string
  default     = "t2.micro"
}

variable "count" {
  description = "Count of VM's"
  type        = number
  default     = 2
}

variable "monitoring" {
  description = "Enable detailed monitoring"
  type        = bool
  default     = true
}

variable "servers" {
  type    = list(string)
  default = ["web1", "web2", "web3"]
}

📄 main.tf

resource "aws_instance" "webserver" {
  ami           = var.ami
  instance_type = var.instance_type
  monitoring    = var.monitoring

  tags = {
    Name = var.servers[0]
  }
}

⚠️ أخطاء شائعة يجب تجنبها

❌ خطأ 1: استخدام provider بدلاً من variable

# ❌ خطأ
provider "instance_type" {
  default = "t2.micro"
}

# ✅ صحيح
variable "instance_type" {
  default = "t2.micro"
}

❌ خطأ 2: نسيان تحديد النوع

دائماً حدد type للمتغير. هذا يساعد في اكتشاف الأخطاء مبكراً ويوثق الكود.

❌ خطأ 3: استخدام قيم حساسة في المتغيرات

لا تضع كلمات المرور أو المفاتيح السرية في default. استخدم متغيرات البيئة أو خدمة إدارة الأسرار.

🎤 أسئلة مقابلات مهمة

سؤال 1: ما هي أنواع البيانات في OpenTofu؟

الأنواع الأساسية: string, number, bool
أنواع المجموعات: list, map, set
الأنواع الهيكلية: object, tuple

سؤال 2: كيف تمرر متغير من سطر الأوامر؟

tofu apply -var "name=value"

سؤال 3: ما هو ترتيب أولوية القيم؟

1. -var من سطر الأوامر (الأعلى)
2. ملف .tfvars
3. متغيرات البيئة TF_VAR_*
4. default في الملف (الأقل)
