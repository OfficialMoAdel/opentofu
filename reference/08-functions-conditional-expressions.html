⚡ OpenTofu - Functions, Operators & Conditional Expressions

مرجع شامل للدوال المدمجة، العوامل، والتعابير الشرطية

📋 نظرة عامة (Overview)

OpenTofu يوفر عشرات الدوال المدمجة لتحويل ومعالجة القيم. يمكن اختبار جميع الدوال والعوامل باستخدام tofu console.

Numeric

max, min, ceil, floor

String

split, join, lower, upper

Collection

length, index, contains

Map

keys, values, lookup

Operators

Arithmetic, Logic, Compare

✅ الـ Console التفاعلي

استخدم tofu console لاختبار جميع الدوال والعوامل قبل استخدامها في الكود. هذا يوفر الوقت ويمنع الأخطاء! 

$ tofu console
> length(var.region)
3
> toset(var.region)
toset([
  "ca-central-1",
  "us-east-1",
])

🔢 الدوال العددية (Numeric Functions)

تُستخدم لتحويل ومعالجة الأرقام.

الدالة الوظيفة مثال النتيجة
max() أكبر رقم max(-1, 2, -10, 200, -250) 200
min() أصغر رقم min(-1, 2, -10, 200, -250) -250
ceil() أقرب عدد صحيح أكبر ceil(10.1) 11
floor() أقرب عدد صحيح أصغر floor(10.9) 10

📄 استخدام المتغيرات مع الدوال

# variables.tf
variable "num" {
  type    = set(number)
  default = [ 250, 10, 11, 5 ]
}

# في الـ console
> max(var.num...)  # ← معامل التوسعة
250

💡 معامل التوسعة ...

عند تمرير متغير من نوع set أو list إلى دالة تتوقع عدة معاملات، استخدم ... لتوسيع العناصر إلى معاملات منفصلة.

📝 دوال النصوص (String Functions)

تُستخدم لتحويل ومعالجة النصوص.

📄 مثال: متغير يحتوي على نص

variable "ami" {
  type    = string
  default = "ami-xyz,AMI-ABC,ami-efg"
}
الدالة الوظيفة مثال النتيجة
split() تقسيم نص إلى قائمة split(",", var.ami) ["ami-xyz", "AMI-ABC", "ami-efg"]
join() دمج قائمة إلى نص join(",", [...]) "ami-xyz,AMI-ABC,ami-efg"
lower() تحويل إلى أحرف صغيرة lower(var.ami) "ami-xyz,ami-abc,ami-efg"
upper() تحويل إلى أحرف كبيرة upper(var.ami) "AMI-XYZ,AMI-ABC,AMI-EFG"
title() أول حرف كبير في كل كلمة title(var.ami) "Ami-Xyz,AMI-ABC,Ami-Efg"
substr() استخراج جزء من النص substr(var.ami, 0, 7) "ami-xyz"

📄 شرح مفصل لـ substr()

# الصيغة: substr(string, offset, length)

# offset = من أين نبدأ (يبدأ من 0)
# length = عدد الأحرف

> substr(var.ami, 0, 7)   # ← أول 7 أحرف
"ami-xyz"

> substr(var.ami, 8, 7)   # ← من الحرف 8، 7 أحرف
"AMI-ABC"

> substr(var.ami, 16, 7)  # ← من الحرف 16، 7 أحرف
"ami-efg"

💡 مثال عملي: إنشاء مستخدمين من نص

# variables.tf
variable "cloud_users" {
  type    = string
  default = "andrew:ken:faraz:mutsumi:peter:steve:braja"
}

# main.tf
resource "aws_iam_user" "cloud" {
  name  = split(":", var.cloud_users)[count.index]
  count = length(split(":", var.cloud_users))
}

📚 دوال المجموعات (Collection Functions)

تُستخدم مع أنواع المجموعات مثل list و set.

الدالة الوظيفة مثال النتيجة
length() عدد العناصر length(var.ami) 3
index() موقع عنصر index(var.ami, "AMI-ABC") 1
element() عنصر في موقع معين element(var.ami, 2) "ami-efg"
contains() هل يوجد العنصر؟ contains(var.ami, "AMI-ABC") true

⚠️ دالة contains() حساسة لحالة الأحرف!

> contains(var.ami, "AMI-ABC")  # ← موجود
true

> contains(var.ami, "AMI-XYZ")  # ← غير موجود (بسبب الحالة)
false

🗺️ دوال الخرائط (Map Functions)

تُستخدم مع نوع map.

📄 مثال: خريطة المناطق

variable "ami" {
  type = map
  default = {
    "us-east-1"    = "ami-xyz"
    "ca-central-1" = "ami-efg"
    "ap-south-1"   = "ami-ABC"
  }
}
الدالة الوظيفة مثال النتيجة
keys() قائمة المفاتيح keys(var.ami) ["ap-south-1", "ca-central-1", "us-east-1"]
values() قائمة القيم values(var.ami) ["ami-ABC", "ami-efg", "ami-xyz"]
lookup() قيمة مفتاح معين lookup(var.ami, "ca-central-1") "ami-efg"

📄 دالة lookup() مع القيمة الافتراضية

# الصيغة: lookup(map, key, default)

# مفتاح موجود
> lookup(var.ami, "ca-central-1")
"ami-efg"

# مفتاح غير موجود ← خطأ بدون قيمة افتراضية
> lookup(var.ami, "us-west-2")
Error: lookup failed to find key 'us-west-2'

# مفتاح غير موجود مع قيمة افتراضية ← يرجع القيمة الافتراضية
> lookup(var.ami, "us-west-2", "ami-pqr")
"ami-pqr"

💡 مثال عملي: اختيار حسب الـ Workspace

# main.tf
resource "aws_instance" "webserver" {
  ami           = var.ami
  instance_type = lookup(var.instance_type, terraform.workspace)
  #                                        ↑                    ↑
  #                                        الخريطة           الـ workspace الحالي
}

⚙️ العوامل (Operators)

يمكن اختبار جميع العوامل في الـ tofu console.

1️⃣ العوامل الحسابية (Arithmetic Operators)

> 8 + 8     # جمع
16
> 8 - 8     # طرح
0
> 2 * 2     # ضرب
4
> 8 / 2     # قسمة
4

2️⃣ عوامل المساواة (Equality Operators)

> 8 == 8     # يساوي تماماً
true
> 8 != 7     # لا يساوي
true
> 8 != "8"   # رقم ≠ نص (مهما كان المحتوى)
true

3️⃣ عوامل المقارنة (Comparison Operators)

> 8 > 9      # أكبر من
false
> 8 > 7      # أكبر من
true
> 8 > 8      # أكبر تماماً من (يساوي لا يُحتسب)
false
> 8 >= 8     # أكبر أو يساوي
true
> 4 < 5      # أصغر من
true
> 3 <= 4     # أصغر أو يساوي
true

4️⃣ العوامل المنطقية (Logical Operators)

# AND: يرجع true فقط إذا كانت كلتا القيمتين true
> 8 > 7 && 8 < 10
true
> 8 > 10 && 8 < 10
false

# OR: يرجع true إذا كانت إحدى القيمتين true
> 8 > 10 || 8 < 10
true

# NOT: يعكس القيمة المنطقية
> var.special       # true
true
> ! var.special     # يعكس إلى false
false
> ! (var.b > 30)    # 25 ليس أكبر من 30، فيرجع true
true

📄 استخدام العوامل مع المتغيرات

# variables.tf
variable "a" {
  type    = number
  default = 50
}

variable "b" {
  type    = number
  default = 25
}

# في الـ console
> var.a > var.b
true
> var.a < var.b
false
> var.a + var.b
75

🔀 التعابير الشرطية (Conditional Expressions)

تُستخدم لاختيار قيمة بناءً على شرط. تشبه if-else في لغات البرمجة.

condition ? true_value : false_value
إذا كان الشرط true ← تُستخدم القيمة بعد ?
إذا كان الشرط false ← تُستخدم القيمة بعد :

📄 مثال عملي: كلمة مرور بطول أدنى

# variables.tf
variable "length" {
  type        = number
  description = "طول كلمة المرور"
}

# main.tf
resource "random_password" "password-generator" {
  # ← التعبير الشرطي
  length = var.length < 8 ? 8 : var.length
  #                    ↑       ↑       ↑
  #                    الشرط   إذا كان صحيحاً   إذا كان خاطئاً
}

output "password" {
  value     = random_password.password-generator.result
  sensitive = true
}

🔍 شرح التعبير الشرطي

var.length < 8 ?

الشرط: هل الطول أقل من 8؟

→
إذا كان true

استخدم 8

أو
إذا كان false

استخدم var.length

🔧 اختبار النتيجة

# طول 5 ← سيتم استخدام 8
tofu apply -var=length=5
# length = 8

# طول 12 ← سيتم استخدام 12
tofu apply -var=length=12
# length = 12

📄 مثال آخر: اختيار نوع الماكينة حسب الـ tag

resource "aws_instance" "mario_servers" {
  ami           = var.ami
  instance_type = var.name == "tiny" ? var.small : var.large
  #                        ↑              ↑              ↑
  #                        الشرط         إذا true       إذا false

  tags = {
    Name = var.name
  }
}

variable "media" {

    "/media/tails.jpg",

  for_each = var.media

⚠️ أخطاء شائعة يجب تجنبها

❌ خطأ 1: نسيان معامل التوسعة ...

# ❌ خطأ - لا يمكن تمرير set مباشرة إلى دالة تتوقع عدة معاملات
max(var.num)

# ✅ صحيح - استخدام معامل التوسعة
max(var.num...)

❌ خطأ 2: مقارنة رقم بنص

# ❌ خطأ - 8 و "8" ليسا متساويين!
8 == "8"  # يرجع false

# ✅ صحيح - نفس النوع
8 == 8      # يرجع true
"8" == "8"  # يرجع true

❌ خطأ 3: contains() حساسة للحالة

دالة contains() تميز بين الأحرف الكبيرة والصغيرة. إذا كنت تبحث عن عنصر، تأكد من الحالة الصحيحة.

❌ خطأ 4: lookup() بدون قيمة افتراضية

إذا كان المفتاح غير موجود، سيرجع خطأ. أضف دائماً قيمة افتراضية:

# ❌ خطر - قد يرجع خطأ
lookup(var.map, "key")

# ✅ آمن - مع قيمة افتراضية
lookup(var.map, "key", "default_value")

🎤 أسئلة مقابلات مهمة

سؤال 1: ما الفرق بين split() و join()؟

split(): يحول نص إلى قائمة باستخدام فاصل معين.
join(): يحول قائمة إلى نص بدمج العناصر مع فاصل معين.

سؤال 2: كيف تستخدم دالة lookup() مع قيمة افتراضية؟

lookup(map, key, default)
إذا كان المفتاح غير موجود، تُرجع القيمة الافتراضية بدلاً من خطأ.

سؤال 3: ما هي صيغة التعبير الشرطي؟

condition ? true_value : false_value
إذا كان الشرط true، تُستخدم القيمة بعد ?. وإلا تُستخدم القيمة بعد :.

سؤال 4: لماذا 8 != "8" يرجع true؟

لأن OpenTofu يقارن الأنواع أيضاً، ليس فقط القيم. 8 رقم و "8" نص، لذلك هما ليسا متساويين.

سؤال 5: ما الفرق بين ceil() و floor()؟

ceil(): أقرب عدد صحيح أكبر أو يساوي.
floor(): أقرب عدد صحيح أصغر أو يساوي.
مثال: ceil(10.1) = 11، floor(10.9) = 10
